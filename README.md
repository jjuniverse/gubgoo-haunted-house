# 급구 유령 테스트 👻

니더 할로윈용 **5문항 테스트 → 유령 결과 → 텍스트 복사** 웹페이지입니다.

- 캐릭터 6종과 특징, 한마디, 찰떡궁합
- 결과와 테스트 링크를 텍스트로 복사해 슬랙 등에 직접 붙여넣기
- 자동 복사가 불가능하면 선택 가능한 텍스트를 표시
- 집 안의 유령이나 도감 버튼을 선택하면 성격·출몰 장소·말버릇·퇴치법 소개
- 선택한 유령의 점프와 부드러운 카메라 이동 (동작 줄이기 설정 존중)
- 테스트 결과에 해당하는 유령 위에 ‘나!’ 표시, 결과 화면에서 바로 찾아가기
- WebGL 미지원 환경에는 SVG 렌더링 사용; 3D 로딩 실패 시에도 도감 버튼 사용 가능
- 로그인, DB, 서버, Slack 앱, 환경변수 설정 없이 실행
- 답변 및 결과는 현재 화면 메모리에만 유지되며 새로고침하면 초기화
- 동료 목록, 사탕 전송, 장난, 슬랙 자동 전송 기능 없음

## 실행

Node.js 24를 사용합니다.

```bash
npm ci
npm run dev
npm test
npm run build
```

## GitHub Pages 배포

저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다. `main`에 push하면 `.github/workflows/pages.yml`에서 테스트와 빌드 후 `dist`를 배포합니다. 별도 Secrets나 Variables는 필요하지 않습니다.

## 구성

- `src/main.js`: 테스트, 결과 화면, 클립보드 복사 및 수동 복사
- `src/data.js`: 질문, 캐릭터, 판정
- `src/share.js`: 복사할 결과 텍스트
- `src/scene.js`: 3D 유령의 집, 선택·카메라·결과 표시
- `src/style.css`: 반응형 화면
- `tests/app.test.js`: 캐릭터 도달성, 일관된 판정, 복사 내용과 링크 검증

이전 서버/DB 코드는 제거했습니다. 테스트 응답을 전송하거나 브라우저 저장소에 기록하지 않습니다. 복사는 사용자가 버튼을 누를 때만 수행합니다. 사이트에서 슬랙으로 메시지를 직접 보내지 않습니다.
